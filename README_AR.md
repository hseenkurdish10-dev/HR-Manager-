# HR Manager - Android APK

## ماذا يحتوي المشروع؟
- واجهة عربية محسنة مستوحاة من الصور التي أرسلتها.
- إضافة/تعديل/حذف الموظفين.
- تسجيل الغياب والإجازات والتأخير والحضور.
- تقارير مع الطباعة/حفظ PDF من نافذة الطباعة في الجهاز.
- تصدير واستعادة نسخة احتياطية JSON.
- البيانات محفوظة محلياً على الجهاز.

## بناء APK من الهاتف عبر GitHub
1. سجّل الدخول إلى GitHub من Chrome وأنشئ مستودعاً جديداً (New repository).
2. ارفع جميع محتويات هذا المجلد إلى المستودع، مع إبقاء مجلد `.github/workflows`.
3. افتح تبويب Actions في المستودع واسمح بتشغيل Actions إذا طُلب منك.
4. اختر workflow باسم Build HR Manager APK ثم اضغط Run workflow.
5. انتظر حتى تنتهي العملية بنجاح.
6. افتح عملية البناء الناجحة، وانزل إلى Artifacts، ثم نزّل HR-Manager-APK.zip.
7. افتح ملف ZIP على هاتفك واستخرج app-debug.apk، ثم افتحه وثبّته. قد يطلب Android السماح بالتثبيت من Chrome أو مدير الملفات.

## ملاحظات مهمة
- هذا بناء تجريبي (debug APK) قابل للتثبيت للاستخدام الشخصي، وليس إصدار متجر Google Play.
- احتفظ بنسخة احتياطية من بيانات التطبيق بشكل دوري؛ البيانات محفوظة على الجهاز ولا تتزامن بين الهواتف.
- لا تحذف التطبيق أو تمسح بياناته قبل تصدير نسخة احتياطية.
- لا ترفع ملفات بيانات الموظفين إلى GitHub؛ ارفع ملفات المشروع فقط.
